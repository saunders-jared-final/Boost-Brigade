\section{Solar Test Records (20 Oct 2026)}
\label{app:solar}
Carpark string of three KAUSSP80 modules into the DL3021 at 61\,V CV, 200\,kHz. Peak sun 15:04--15:13 (S01 open loop, S02 closed loop $k=0.1$), minimal sun from 15:48 (S03 open loop, S04--S11 closed loop, $k = 0.1$ to 0.8). Module currents are reconstructed by KCL from the winding currents, duties and the e-load current. The baseline with the shufflers idle is in the e-load log of the minute before each run: 6.0--6.5\,W before S01, 2.9--3.7\,W before S02 and 0.4--1.2\,W before the minimal-sun windows, with the shaded module pulled down to 14--18\,V. Earlier open-loop runs (12:53, full sun) reached 176\,W at the load when the shufflers were switched on, against about 40\,W with them off; the current sensors were not yet working in that run, so it is not in the tables.
